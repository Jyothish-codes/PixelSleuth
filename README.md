🔍 PixelSleuth – Image Forensics
PixelSleuth is an AI-assisted image forensic tool designed to analyze digital images and identify potential signs of manipulation. It combines multiple forensic techniques to provide a clearer understanding of whether an image may have been altered.
🔎 Key Features
- C2PA Provenance Check – checks available content authenticity and provenance information.
- Noise Residual Analysis – examines image noise patterns for inconsistencies that may indicate manipulation.
- Image Forensic Analysis – extracts technical signals from the uploaded image.
- AI-Assisted Explanation – uses AI to explain the forensic findings in simple language.
- Web Interface – allows users to upload an image and view the analysis through a simple frontend.
🛠️ Technologies Used
- Python
- FastAPI
- HTML/CSS/Bootstrap
- Pillow
- NumPy
- C2PA
- PyTorch / Transformers
- Google Gemini
